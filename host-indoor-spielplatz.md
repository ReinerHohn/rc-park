# Sweet Spot: RC-Baustellenwelt bei einem bemannten Indoor-Spielplatz

> Statt eigenem Laden: die RC-Baustelle als **Shop-in-Shop** bei einem Indoor-Spielplatz, der
> **eh Personal + Familien + Schlechtwetter-Publikum** hat. Du bringst nur die RC-Gear →
> **kein eigenes Personal, kein Mietvertrag-Risiko.** Genau deine Zielgruppe (Kinder lieben Bagger!).

## 🥇 Top-Host: KinderGalaxie Freiburg
- **Lage:** Basler Landstr. 17, Freiburg-St. Georgen. **~2.600–5.000 m²** Indoor.
- **Hat schon:** Trampolin, **Kartbahn**, Wellenrutsche, Hüpfburg, **Lasergame**, Indoor-Soccer,
  Billard, Kleinkindbereich. → **Sie bauen ihr Angebot aus Modulen** (Kart/Laser) → eine
  **RC-Baustelle passt perfekt ins Konzept.**
- **Publikum:** Familien mit Kindern, ganzjährig, Schlechtwetter — exakt dein Zielmarkt.
- **Preise dort:** einheitlicher Eintritt (Kind = Erwachsener), VielSpiel-Karte 60 €/10 Besuche.

## Weitere Host-Kandidaten (Umgebung)
Impulsiv Kinderland (Emmendingen), Tengu (Endingen), Tropilua (Hilzingen), Kiddy Dome (~50 min),
Fundorena (Feldberg). → Kindergalaxie ist der größte/nächste **in Freiburg selbst**.

## 💶 Das Modell: Umsatzbeteiligung (risikoärmster Weg)
| Modell | Wie | Risiko |
|---|---|---|
| **★ Umsatzbeteiligung** | du stellst RC-Baustelle, Host gibt Fläche+Aufsicht+Laufkundschaft, ihr **teilt die Jeton-/Session-Erlöse** (z. B. du 60–70 % / Host 30–40 %) | **minimal** — zahlst nur, wenn du verdienst |
| Flächenmiete | feste Miete für die Ecke, du behältst allen Umsatz | mittel (Fixkosten) |
| Hybrid | kleine Miete + kleinerer Umsatzanteil | mittel |

**Empfehlung: Umsatzbeteiligung** — keine Fixkosten, Host ist motiviert (verdient mit), du
startest fast risikofrei. **Wer macht was:** du = Gear + Wartung/Reparatur (paar Std/Woche) +
Jeton-System; Host = Fläche + Aufsicht (sein Personal) + Werbung an seine Gäste.

## Markt-Kontext (warum Hosts „ja" sagen)
~**400 Indoor-Spielplätze** in DE, **>30 Mio Besucher/Jahr**; profitabelste erreichen ~20 %
Gewinn **gerade mit Modul-Add-ons** (z. B. VR-Zonen, modulares Design). Eine **RC-Baustelle ist
genau so ein attraktives Zusatzmodul** → bringt dem Host neue Attraktion + Mehrumsatz ohne eigenes Invest.

## Caveats / Verhandlung
- RC-Bagger brauchen **mehr Betreuung/Wartung** als ein statisches Spielelement → im Deal klären
  (du übernimmst Wartung; Host-Personal nur Basis-Aufsicht/Jeton).
- **Umsatzanteil** + Haftung/Versicherung + Fläche/Strom schriftlich fixieren.
- **Als Pilot starten**: 1 Ecke, 3–5 Maschinen, 2–3 Monate testen → bei Erfolg ausbauen.
