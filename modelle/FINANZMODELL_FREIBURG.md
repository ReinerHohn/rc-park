# Finanzmodell „Freiburger Miniatur-Wunderland" — 3 Szenarien + Break-even

Pitch-Material für Stadt/Förderung. Basis = echte Zahlen (2024). Alle Beträge grob, bewusst
**konservativ** gerechnet. Prinzip: zeigt, dass schon die kleine Stufe sich selbst trägt und
die mittlere Stufe (Hausach-Größe) klar profitabel ist. Siehe [[FREIBURG_STRATEGIE.md]] · [[miwula_freiburg_pitch]].

---

## 0. Die harten Anker (belegt)
- **Freiburg-Tourismus 2024:** 2,17 Mio. Übernachtungen, ~1,0 Mio. Gäste-Anreisen, ~29 % Ausland,
  Ø 2–3 Nächte. Dazu Millionen **Tagesgäste** (Schwarzwald-Tor, Nähe FR/CH) = Upside, hier nicht mal eingerechnet.
- **Freiburg + Umland:** Stadt ~235.000 EW, Region Breisgau ~660.000 → starker Lokal- & Schulklassen-Sockel.
- **Benchmark oben (Miniatur Wunderland Hamburg 2024):** 1,6 Mio. Besucher, **42,7 Mio. € Umsatz**
  = **~27 €/Kopf** (Ticket 22 €/Kind 13 € + Shop/Café), 448 MA (~300 FTE). = die Decke, nicht das Ziel.
- **Hausach (geschlossen 2019):** ~100.000/Jahr in einem **6.000-EW-Ort**, rein als Destination.
  → In Freiburg (40× mehr Einwohner + 2,17 Mio. Übernachtungen) sind 45–120k **plausibel**.

**Kostenlogik:** Variable Kosten pro Besucher sind bei so einer Anlage winzig (~0,5 €).
Also ist es ein **Fixkosten-Spiel** → Break-even ≈ Fixkosten ÷ Ertrag pro Kopf. Der größte Fixblock
ist **Personal, nicht Miete** (deine Frage: ja, Miete ist easy bezahlbar — die Löhne sind der Hebel).

## 1. Drei Szenarien

### 🟢 KLEIN — Pop-up / Startphase (Jahr 1–2), ~150 m²
e.V.-getragen, viel Ehrenamt + 1 Teilzeitkraft, Öffnung Fr–So + Ferien.

| | |
|---|---|
| Besucher/Jahr | **15.000** (≈1,5 % der Übernachtungsgäste + Lokal/Schulen — sehr konservativ) |
| Ertrag/Kopf | 7 € (Erw 9 / Kind 5 / Familie) + bisschen Shop |
| **Umsatz** | **~120.000 €** |
| Kosten | Miete ~22k · Personal (1 TZ + Ehrenamt) ~35k · Strom/Wartung ~12k · Versich./Marketing/Verw. ~18k = **~87k** |
| **Ergebnis** | **~+30.000 €** (trägt sich — dank Ehrenamt) |
| **Break-even** | **~12.400 Besucher = ~45/Tag** (Fr–So) ✅ sehr erreichbar |

### 🟡 MITTEL — feste Location, Hausach-Größe (Jahr 3–5), ~400 m²
7 Tage offen, 4–5 feste Kräfte, etablierter Ruf.

| | |
|---|---|
| Besucher/Jahr | **45.000** (≈4–5 % Übernachtungsgäste + Schulen + Tagestouristen; unter Hausachs 100k, weil Ruf erst wächst) |
| Ertrag/Kopf | 9 € Ticket + ~2 € Shop/Café = **11 €** |
| **Umsatz** | **~495.000 €** |
| Kosten | Miete 400 m² ~67k · Personal 4,5 FTE ~170k · Strom/Wartung ~40k · Marketing ~35k · Versich./Verw./Abschr. ~55k = **~367k** |
| **Ergebnis** | **~+128.000 €/Jahr** (finanziert sich + Reinvestition) |
| **Break-even** | **~33.400 Besucher = ~110/Tag** |

### 🔴 GROSS — Destination mit Stadt-Partnerschaft (Zielbild), ~1.000 m²
Hamburg-lite, Profi-Marketing, Bus-/Tourismus-Anbindung.

| | |
|---|---|
| Besucher/Jahr | **120.000** (über Hausach — größerer Sockel + Stadt-Rückhalt + moderne Attraktion) |

| **Ergebnis** | **~+680.000 €/Jahr** |
| **Break-even** | **~77.500 Besucher = ~230/Tag** |

## 2. Was das für den Pitch heißt
1. **Schon KLEIN wäscht sich selbst** (Break-even ~45 Gäste/Tag). Risiko minimal → ideal zum Beweisen.
2. **MITTEL (Hausach-Größe) macht ~130k €/Jahr Überschuss.** Das ist kein Hobby mehr, das ist ein Betrieb.
3. **GROSS ist ein echter Arbeitgeber** (14 Stellen) und Tourismus-Magnet — genau das, was eine Stadt fördert.
4. **Dein struktureller Kostenvorteil ggü. Hausach:** du **druckst** Gelände/Gebäude/Wahrzeichen für Cent-Beträge
   (echte Topografie gratis, 3D-Druck statt Kauf) → **drastisch niedrigere Baukosten (Capex)** als eine klassisch
   handgebaute Anlage. Hausachs Aufbau verschlang Jahre und ein Vermögen; deiner skaliert fast umsonst.
5. **Der Hebel ist Personal, nicht Miete** → e.V. + Ehrenamt + evtl. Inklusions-/Ehrenamtsmodelle halten die
   teuerste Position klein. Das entscheidet über Gewinn/Verlust.

## 3. Warnung aus dem Hausach-Fall
Hausach schloss **trotz** 1,5 Mio. Besuchern — nicht an Gästen gescheitert, sondern an Betreiber/Gebäude/Nachfolge.
→ **Trägerstruktur (e.V. + mehrere Schultern + Stadt als Partner)** sichert Dauerhaftigkeit, nicht die Besucherzahl allein.

## 4. Offene Punkte / zu schärfen vor dem Stadt-Pitch
- Tagesgäste-Zahl Freiburg sauber belegen (erhöht alle Szenarien).
- Reale Mietangebote (FWTM-Pop-up, Gewerbehalle Randlage ~6,90 €/m²) einsetzen statt Schätzung.
- Förderquote (Kulturamt, TIP-BW, Crowdfunding-Anteil) in Capex gegenrechnen.
- Ø-Ertrag/Kopf mit echtem Preismodell (Familienticket, Jahreskarte, Schulklassen) verfeinern.
