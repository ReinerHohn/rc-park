# Wartung & Risiko: RC-Aktion vs. Display — und der kluge Mittelweg

> User-Einwand (richtig!): **RC-Bagger haben viele Verschleiß-/Bruchteile → viel Wartung +
> Risiko.** Ein **Miniaturwunderland (Display)** braucht viel weniger Wartung.
> → Lösung: **low-maintenance Interaktivität** statt fragiler RC-Technik als Kern.

## Der Trade-off ehrlich
| | **RC-Aktion** (Bagger/FPV) | **Display-Miniaturwunderland** |
|---|---|---|
| Engagement/Wiederkehr | **hoch** (selbst steuern) | niedriger (zuschauen) |
| Umsatz/Besucher | hoch (Sessions/Jetons) | niedriger |
| **Wartung** | **hoch** (Motoren, Servos, Hydraulik, Akkus, Crashs) | **niedrig** (meist statisch) |
| Aufsicht/Personal | mehr | weniger |
| Risiko/Ausfall | höher | gering |

→ RC = umsatzstark aber pflegeintensiv; Display = pflegeleicht aber passiv.

## 🎯 Der kluge Mittelweg: low-maintenance Interaktivität
Interaktiv heißt **nicht zwingend fragile RC-Technik**. Robuste, wartungsarme Mitmach-Elemente:
- **Knopfdruck-Animationen** (wie Miniatur Wunderland): Besucher drückt Knopf → eine Szene
  leuchtet / ein Kran fährt auf **Schiene** / Feuerwehr fährt eine **feste Runde**. Kaum Verschleiß.
- **Tag-Nacht-Lichtshow** — **null bewegliche Teile**, großer Wow (beleuchtetes Münster!).
- **Suchspiele** („Finde die 10 versteckten Details / die Bächle-Ente") — **null Wartung**,
  bindet Kinder lange.
- **Schau-Druckfarm** — druckt Modelle vor Publikum: Attraktion **und** Produktion, robust.
- **Schienengeführte Fahrzeuge** (Car-System/Modellbahn) statt freier RC → viel weniger Crash
  als von Besuchern frei gesteuerte Bagger.

## Empfehlung
1. **Start = pflegeleichtes Mini-Freiburg**: gedruckte/gekaufte Stadt (LoD2/OSM + Faller) +
   **Knopf-Animationen** + **Tag-Nacht-Licht** + **Schau-Druckfarm** + Suchspiele.
   → **wenig Wartung, wenig Personal, geringes Risiko** — ideal fürs Host-Modell (Kindergalaxie),
   weil das Host-Personal nichts Komplexes betreuen muss.
2. **RC-Aktion nur robust + optional**: falls Bagger, dann **Getriebe statt Hydraulik** (weniger
   Teile), im **Plexiglaskasten** (weniger Crash/Diebstahl), **Ersatzteil-Lager + Modultausch**
   (Downtime gering) — und eher als **betreute Premium-Ecke**, nicht als wartungsintensiver Kern.
3. **FPV** erst später (eigenes Thema, mehr Aufwand).

→ So bekommst du **Mitmach-Reiz mit Display-Wartungsniveau**. Die umsatzstarke, aber
pflegeintensive RC-Aktion kommt erst dazu, wenn Betrieb + Wartung stehen.
